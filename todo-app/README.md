# 📝 React To-Do List App

A simple, responsive and interactive To-Do List application built using **React**. It allows users to add, edit, complete, and delete tasks — with data persistence using `localStorage`.

---

## 🚀 Features

- ✅ Add new tasks
- ✏️ Edit existing tasks
- ❌ Delete tasks
- 📁 Mark tasks as completed
- 💾 Automatically saves tasks to `localStorage`
- 🎨 Responsive UI with Tailwind CSS
- ⚡ Fast and lightweight with Vite

---



## 🛠️ Tech Stack

- **React**
- **Vite**
- **Tailwind CSS**
- **UUID** (for unique task IDs)
- **LocalStorage API**
